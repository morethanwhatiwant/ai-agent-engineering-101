# 전략상품 셀러·바이어 연계 (2026-11-04)

## 적용 동작
- 공급 opens_at 180초 전부터 최신 공개 shops와 정산 tail을 조회해 해당 창의 TOP10을 한 번 저장한다. 재시작은 같은 창의 저장 결과를 재사용한다. 뒤늦게 실행했다면 late 표시를 남긴다. 데이터 확보 실패 시 재시도하며 오래된 결과를 새 창에 쓰지 않는다.
- 최근6시간 수집된 honest·보증6h 비식품 체결이3건 이상이며 체결가가 관측 비식품 상위25%인 SKU를 후보로 삼는다. 점수=관측거래수×체결중앙값/((경쟁재고+1)×sqrt(경쟁가게수+1)). 최대10개, 조건 충족 후보 부족 시 억지로 채우지 않는다. 이는 공개 체결 수요의 대리 지표이며 모든 바이어의 미체결 주문 수요가 아니다.
- 기존 재고가 늘수록 score/(1+보유수량)으로 발주 우선순위를 낮춘다. 수량 상한은 없다. 최대 매입가(정가75%)를 감당할 수 있는 후보만 고르며 누적250만원·50만원현금·기존 보증 전액 보호는 유지한다. 공급 응답 성공 시에만 SQLite paid 처리한다.
- buyer는 매 주문마다 paid SKU와 120초 이내 갱신된 실제 비식품 재고의 교집합을 읽는다. 이미 서명 영수증이 발행된 재고는 제외한다. 현 주문 acceptable과 교집합이 없으면 구매를 건너뛴다. 과거 전략 SKU도 실제 보유 중이면 대상이다.
- 가격 상한·등급·6h 보증·서명검증·자가거래 차단을 유지한다. 경쟁재고 소진을 위해 웃돈을 지급하거나 주문 밖의 상품을 사지 않는다. 경쟁 재고가 다시 공급될 수 있어 독점 달성을 보장하지 않는다.

## 운영 확인
기존 워커가 예산 잔액 부족으로 종료했음을 확인하고 새 코드로 지속 실행. 이전10개 매입2,353,607/잔액146,393 유지. 예산 부족 시에도 다음 창 TOP10 관측을 이어가되 예산을 자동 증액/초기화하지 않는다. buyer는 주문별 새 프로세스이므로 부모 재시작 불필요. 14:53 실제 주문에서 no owned strategic SKU→구매 건너뜀을 확인했다. 전략상품 구매 실정산과 경쟁재고 감소는 아직 별도 검증이 필요하다.

실시간 데이터 TOP10 사전 실행 검증은 strategy-preview.json으로 분리했으며 실제 창의3분 전 스냅샷으로 사용하지 않는다. 새 발주 워커의 waiting_selection 로그로 운영 적용을 확인한다.
