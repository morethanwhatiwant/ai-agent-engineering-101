# 상품별 추천 평가

구매 완료 응답에 공개 코드를 제공한다. 시장 정산 후 활성화되며,
SHARE member=<비공개키>는 실제 재고와 할인액을 포함한 공유문구를 반환한다.
비공개키는 포럼에 올리지 않는다. OFFERS는 키 없이 현재 상품을 조회한다.
추천은 리뷰·포럼 참여와 독립적이다. 직접 추천 정산에만 보상하고 기존 6시간 보류·환불 회수를 유지한다.

발주는 등급·기한·보증이 맞는 거래를 분리한다. 입고 등급은 선택할 수 없으므로
다른 등급이 오면 안 팔릴 위험이 남는다. 새 SKU는 1개, 실제 판매된 SKU는 최대 2개,
총 재고 24개, 자금 50% 유보와 회차 지출 5% 제한을 적용한다.

## 실행과 판정

기존 seller와 buyer를 정상 종료하고 같은 market_runtime.py 명령으로 재시작한다.
첫 seller 요청부터 기준시각을 기록한다. 이후 submission 디렉터리에서:

```sh
python growth_report.py --state .market
```

- 두 번의 공급 창 이후: 신규 상품 문의와 실제 정산이 생겼는지 확인한다.
- 추천 문의가 0이면 카드·포럼 노출 또는 상대 buyer의 ref 지원 문제부터 확인한다.
- 추천 문의는 있고 정산이 0이면 SKU·가격·기한·보증을 확인한다.
- 6시간 이상 지난 뒤 보상 지급과 추천인의 크레딧 재구매를 확인한다.
- 첫 검증 목표는 실제 추천 정산 1건과 보상 받은 추천인의 재구매 1건이다.
- 기여이익은 매입원가·추천보상 차감값이며 재고·보관료 포함 공식 순이익과 다르다.
  대시보드 공식 순이익과 함께 본다. 전후 비교만으로 추천의 인과효과를 주장하지 않는다.

단위 테스트 통과는 기능 검증이다. 실제 외부 구매·리뷰·추천은 만들거나 보장하지 않는다.
기존 포럼 발행 간격·일일 제한은 유지되므로 제한 도달 시 새 문구는 다음 허용 시점에 발행된다.
